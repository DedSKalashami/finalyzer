# Finance Analyzer

Анализатор личных финансов - консольное Python-приложение для анализа расходов.  
Загружает данные из CSV-файла (в том числе выгрузки из Т-Банка), считает статистику и строит графики.

---

## Структура проекта

```
finalyzer/
│
├── src/
│   ├── analysator.py     # вся аналитика (6 методов анализа)
│   ├── loader.py         # загрузка, добавление трат, генераторы
│   ├── display.py        # интерфейс: меню, баннер, подменю
│   └── decorators.py     # декораторы: логирование и форматирование вывода
│
├── data/
│   └── expenses.csv      # файл с расходами (создаётся автоматически)
│
├── logs/                 # логи вызовов функций (создаётся автоматически)
│
├── test_analysator.py    # тесты pytest
├── conftest.py           # настройки pytest
├── main.py               # точка входа, CLI через argparse
├── requirements.txt
└── README.md
```

## Запуск

```bash

# Импортировать CSV из Т-Банка
python main.py import --file путь/к/файлу.csv

# Интерактивное меню (по умолчанию)
python main.py

# Быстрая сводка по расходам
python main.py stats

# Полный отчёт по всем выводам
python main.py report

# Открыть меню аналитики
python main.py analyze

# Добавить новую трату вручную
python main.py add

# Показать траты выше порога (по умолчанию 3000 руб)
python main.py expensive
python main.py expensive --threshold 5000

# Изменить количество топ-категорий
python main.py stats --top 3

```

## Что умеет анализировать

| # | Функция               | Описание                                         |
|---|-----------------------|--------------------------------------------------|
| 1 | Топ категорий         | Какие категории съедают больше всего денег       |
| 2 | Лучший и худший месяц | Сравнение расходов по месяцам                    |
| 3 | Выходные vs будни     | Где тратишь больше за одну покупку               |
| 4 | Стабильность расходов | Среднее, медиана, стандартное отклонение (numpy) |
| 5 | Самый дорогой день    | Дата с максимальными расходами                   |
| 6 | Динамика расходов     | Тренд: растут или падают расходы (numpy polyfit) |

Также доступны:
- График динамики расходов по месяцам (matplotlib)
- Круговая диаграмма по категориям
- Можно запустить программу со своим csv из расходов Т-Банка

## Загрузка данных

**Вариант 1 - данные из Т-Банка:**  
Зайди в приложение → История → Выгрузить в CSV → Переместить в папку data/ → Переименовать в tbank.csv
Затем запусти:
```bash
python main.py import --file выгрузка.csv
```

**Вариант 2 - добавить вручную:**
```bash
python main.py add
```
Программа попросит ввести дату, категорию, описание и сумму.

## Тесты

```bash
pytest test_analysator.py -v
```

Тесты покрывают:
- инициализацию и подготовку данных
- все 6 аналитических методов
- оба генератора
- граничные случаи (одна строка, все одной категории, нет выходных)

## Реализованные паттерны

**Декораторы:**
- `@log_action` - логирует каждый вызов функции в файл `logs/session_*.txt`
- `@format_output` - оборачивает вывод аналитики в красивые рамки

**Генераторы:**
- `unique_categories()` - перебирает уникальные категории по одной
- `get_expensive_transactions()` - фильтрует крупные траты выше порога
- `generate_rows()` - читает CSV построчно без загрузки всего файла в память
- `generate_by_category()` - фильтрует строки по категории через генератор
